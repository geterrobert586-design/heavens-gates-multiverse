# Heavens Gates Content Command Center Plan

## Purpose

The app should not become a random collection of pages. It should operate like a creative command center for the Heavens Gates universe.

## Content lanes

### Canon lane

- Books
- Chapters
- Timeline events
- Characters
- Bloodlines
- Locations
- Lore entries
- Doctrine entries

### Music lane

- Tracks
- Beats
- Soundtrack placements
- Beat licenses
- Promo videos
- Narration/audio files

### Commerce lane

- Ebook products
- Bundle offers
- Beat checkout
- License delivery
- Payment success screens
- Purchase records

### Community lane

- Reader notes
- Fan theories
- Community feedback
- Character questions
- Barry Parker chat prompts

### Protection lane

- Copyright notice
- Terms of use
- Licensing rules
- Admin-only controls
- Content ownership records
- File backup process

## Recommended admin workflow

1. Draft content outside the app first.
2. Add it into the correct content lane.
3. Mark whether it is public, private, locked, paid, or admin-only.
4. Review for canon consistency.
5. Publish only after ownership/copyright review.
6. Back up the project and exported data after each major content push.
